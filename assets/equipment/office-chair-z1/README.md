# 云坐 Z1 人体工学椅 · 灰框灰网脚托款

## 预览

在设备库中选择「03 · 云坐 Z1 人体工学椅」，或访问 `/?model=office-chair-z1#chair`。构建后双击 `dist/chair.html` 可离线查看。

支持立体、正面、右侧、背面和俯视；可切换 135° 后仰与脚托展开姿态，添加到办公室、导出视图、下载 GLB 和尺寸参数。

## 尺寸依据

- 扶手外宽 / 五爪脚直径：660 mm；收纳深度按模型外形估算并取整预留为 700 mm，摆放占地为 660 × 700 mm。
- 座面：500 × 500 mm；腰托宽 460 mm；头枕宽 370 mm。
- 图示座高 450–550 mm，总高 1080–1280 mm；默认采用座高 500 mm、总高约 1180 mm。
- 图示扶手高度 690–790 mm，头枕调节行程 100 mm，最大后仰 135°。
- 网面弧度、背框厚度、脚轮直径、各连接件及脚托行程按外观图估算，详见 `equipment.json` 的 `inferred`。

## 模型结构

曲面鱼骨纹透孔网面、灰色框架、分体上背与独立腰托、曲面头枕及滑轨、背面 Y 字支撑、伸缩扶手与软垫、同步倾仰底盘与升降拨杆、金属气杆、五爪底座、五组双轮脚轮、可收纳的双导轨网面脚托。

后仰靠背和脚托是独立命名组件，可由 `setChairLounge` 切换展示姿态。头枕、腰托及扶手分件建模，未模拟全部调节自由度。

## 文件

- `reference.png`：用户提供的外观参考图。
- `dimensions.png`：用户提供的尺寸图。
- `equipment.json`：尺寸、材质、调节范围及估算参数。
- `model.glb`：直立收纳姿态，米为单位，+Y 向上、+Z 朝前，原点在地面占地中心，内嵌透孔网纹。
- `../../../src/equipment/office-chair.js`：程序化模型源文件。

运行 `npm run equipment:export` 重新导出模型，`npm run build` 生成网站和离线预览。网面采用内嵌透明孔隙贴图，以 glTF 标准透明材质保留近处编织纹理与远处透光效果。模型用于空间布局和外观预览。
