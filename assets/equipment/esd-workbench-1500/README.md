# 防静电操作台

## 预览入口

启动项目后，点击顶部「设备库」或左侧操作台图标；也可访问 `/#equipment`。支持立体、俯视、正面、背面和右侧预览，工作灯开关、参考图查看、GLB / 设备信息下载，以及放入办公室与移出。设备界面用毫米标注尺寸。

## 尺寸与结构

- 台面：1500 × 750 mm，台面高 800 mm，总厚 50 mm，深墨绿色哑光表面、黑色包边。
- 台面以上双层背板：高 1000 mm，整机总高 **1800 mm**。
- 挂板：1.0 mm 工业冷轧钢，模型采用真实开孔。
- 桌腿：C 型截面 100 × 45 mm，壁厚 1.7 mm，含调平脚。
- 顶层搁板下设置条形工作灯，右侧带开关；参考图插座为外形占位。
- 搁板深度、孔距、横梁和上部立柱截面按图片估算，集中记录在设备信息的 `inferred` 中。台面内部基材、承重、防静电性能和电气参数待补充。

## 设备文件

参考图、设备档案和可复用模型位于本文件夹：

- [reference.png](reference.png)：原始四视角参考图。
- [equipment.json](equipment.json)：尺寸、材料、已确认参数、估算参数、摆放建议。
- [model.glb](model.glb)：独立模型，单位米，+Y 向上、+Z 为正面，原点在地面占地中心。

## 办公室摆放与交互

操作台默认放在西侧白墙中段，背面距墙约 100 mm，正面朝室内；前方建议预留 1000 mm。支持重复添加，每件可独立选中、移动、旋转与移出。

- 点击模型选中，直接拖动台体在地面移动，拖动完整圆环可旋转 360°；切换「移动」也可用 X/Z 操纵轴。右侧保留中心距墙距离和转角精调。
- 「定位」拉近设备查看；底部浮动条可切换移动、旋转、工作灯，或结束编辑。
- 右下角户型图实时同步占地、朝向、选中状态和灯光；也可直接拖动绿色操作台移动。
- 台体、操纵轴和户型图移动统一自动吸附 1 cm 网格，移动时显示局部网格。
- 旋转圆环每 15° 显示固定刻度，90° 方向加粗；按住拖动到刻度附近自动吸附、高亮并显示角度，继续拖动可脱离。
- 选中时方向键移动 1 cm，Shift + 方向键移动 5 cm，R / Shift + R 转动 ±15°，L 开关工作灯，Esc 结束编辑。
- 旋转后的完整占地会限制在房间内；位置、朝向、灯光和是否放置自动保存在本机浏览器，刷新可恢复，并兼容原先单张操作台的保存数据。

## 开发与导出

参数化构建函数为 [src/equipment/workbench.js](../../../src/equipment/workbench.js)。在项目根目录运行 `npm run equipment:export` 重新生成 GLB；`npm run build` 也会先生成模型，再构建含图片和 GLB 的完整离线页面。

- [src/equipment/catalog.js](../../../src/equipment/catalog.js)：设备档案、材料、参考图、下载资源和入口地址。
- [src/equipment/layout.js](../../../src/equipment/layout.js)：摆放、吸附和旋转逻辑，模型尺寸不随移动和旋转改变。
- [src/components/EquipmentInspector.jsx](../../../src/components/EquipmentInspector.jsx)：共用设备详情面板。
- [src/components/EquipmentPicker.jsx](../../../src/components/EquipmentPicker.jsx)：添加物品按钮与右键菜单共用的选择器。

设备工作区与房间共用同一个 React 应用和 Three.js 渲染器，切换时不重新加载页面；页面样式统一在 [src/style.css](../../../src/style.css) 中维护。
